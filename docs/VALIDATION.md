# Release validation

## Paper synchronization — 2026-11-16

The documentation and result bundle were synchronized with the current paper, **Distilling Visual Agents from Limited Interaction Experience**. Training/runtime code and bundled trajectory/image examples are unchanged. On the CPU compute node, all **30 existing contract tests passed again**, and the result plotting command produced a PDF.

The refresh additionally checked the 4B/9B README table, all 15 offline/online budget rows, and four-run mean/standard-deviation summaries against paper snapshots. All **480 monitoring points** match the paper files byte for byte; all four published figure images retain the original paper bytes. Local Markdown targets resolve. [The publication manifest](../results/publication_manifest.json) records the paper revision and file hashes. Collaborator results retain their reported provenance; these checks do not imply raw-log verification.

## Package validation

This package was extracted from the completed formal 100-update experiments. The public entrypoints remove private scheduler, host, path and deployment assumptions; **the portable package has not been retrained end to end on GPUs as part of this release**. Ongoing experiments were not interrupted to perform a redundant training run.

Verified on a CPU compute node:

- 30 tests passed with Python 3.10.12: causal prefix exclusion, original message preservation, deterministic two-stage replay draws, matched SFT label attachment and hash rejection, complete fixed evaluation schedules, exact task/repeat denominators, continuous SpatialGym scores, online credits/version contracts, and fail-closed rendering supervision using isolated fault fixtures.
- The bundled four trajectories build ten unique prefixes and the configured draw budget. Image references resolve. The frozen example image bytes are unchanged.
- Shell syntax, Python syntax, local Markdown links and release-file boundaries are checked. No selection implementation, private host/IP/path, API secret, checkpoint or HTML application is included.
- The result plot script produces a standalone PDF from the real aggregate table. Published curves are copied from measured records, not generated by the tests.

These checks do **not** run a model, claim successful installation of simulator assets on arbitrary machines, establish GPU memory feasibility, or replace numerical equivalence checks for a different Slime/SGLang build. The original integration hooks were exercised in the authors' GPU experiments; the portable orchestration needs a deployment-specific GPU preflight.

Run the lightweight checks with:

```bash
PYTHONPATH=.:training:scripts python -m unittest discover -s tests -v
# Or after installing the optional test dependency:
python -m pytest -q tests
```

`integration_tests/test_native_async.py` additionally tests Slime's actual asynchronous worker and importance-sampling path using mocked environment/model I/O. Run it only inside a compatible training container on a compute node; it imports Slime/Torch and is excluded from the lightweight test command above.

Published rendering protection requires an explicit authorized hostname, a live supervisor, readable kernel logs and untripped state. Fault tests simulate kernel events in temporary files; they never provoke GPU faults.
